# **Concept2Paper: генерация научных идей и драфтов статей на основе графа концептов**

## 1. Бизнес-анализ (Business Understanding)

### Цель проекта  
Создать интеллектуальную систему, которая:
- анализирует научные статьи выбранной конференции (например, ICLR),
- извлекает ключевые концепты,
- строит граф взаимосвязей между ними,
- предсказывает новые потенциально перспективные комбинации концептов,
- генерирует драфт абстракта научной статьи с помощью LLM.

### Бизнес-задачи  
- Ускорение процесса генерации научных идей  
- Поддержка исследователей в поиске новых направлений  
- Повышение количества и качества публикаций  
- Снижение барьера входа для начинающих исследователей  

### Пользователи и стейкхолдеры  

**Основные пользователи:**
- Исследователи (ML/AI)  
- Аспиранты и студенты  
- R&D команды  

**Стейкхолдеры:**
- Заказчик (AI-компания / университет / лаборатория)  
- Data Science команда  
- ML инженеры  
- NLP специалисты  
- Доменные эксперты  

### Анализ существующих решений  

**Что уже есть:**
- LLM (например, GPT-подобные модели)  
- Semantic search по статьям  
- Рекомендательные системы статей  

**Недостатки:**
- Генерация идей неструктурирована
- Нет явного механизма генерации *новых комбинаций концептов*

### 1.1.3 Риски и их снижение  

| Риск | Описание | Как снижаем |
|------|--------|------------|
| Сроки | Недооценка сложности | MVP + итеративная разработка |

## 1.2 Data Mining Goals

### 1.2.1 Формализация задачи  

**Подзадачи:**
1. Извлечение концептов (NLP)  
2. Построение графа (co-occurrence graph)  
3. Предсказание новых связей (link prediction)  
4. Генерация текста (LLM)  

---

### 1.2.2 Метрики  

**Для графовой модели:**
- AUC  
- Precision@K
- Hits@K  

**Для генерации:**
- ROUGE / BLEU (вспомогательные)  
- Perplexity  
- Human evaluation (ключевая метрика)  

---

### 1.2.3 Критерии успеха  

- AUC ≥ 0.7 (baseline → 0.8 target)  
- Precision@10 ≥ 0.5  
- ≥ 70% идей признаны полезными экспертами  
- Генерация:
  - логичность  
  - новизна  
  - соответствие конференции  

---

### 1.2.4 Подходы  

**Извлечение концептов:**
- TF-IDF  
- RAKE
- KeyBERT  
- LLM 

**Граф:**
- Взвешенный граф  
- Рёбра = частота совместного появления  

**Модели:**
- Node2Vec  
- Graph Neural Networks  
- Link Prediction

## 1.3 План проекта (Project Plan)

### 1.3.1 Этапы проекта  

| Этап | Задачи |
|------|-----|
| Data Collection | Сбор статей ICLR и приведение к единому формату  |
